# Waste Management and Health Awareness App 🌱

A simple desktop application developed using Python and Tkinter to promote
proper waste management, environmental cleanliness, and healthy living.

## Features

- ♻ Waste Management Guidelines
- 🗑 Wet and Dry Waste Segregation
- ❤️ Health Awareness Tips
- 🌱 Environmental Awareness
- 💧 Healthy Lifestyle Tips
- 🧼 Hygiene Awareness
- 🖥 Simple and User-Friendly GUI

## Technologies Used

- Python
- Tkinter
- MessageBox

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python waste_health_app.py
